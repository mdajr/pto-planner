# PTO Planner

Note: This project was generated collaboratively using Google Gemini and OpenAI ChatGPT.

PTO Planner is a lightweight, client‑side web tool to plan future paid time off. It simulates monthly accruals, caps, and year‑end rollover, and lets you add named vacations over arbitrary date ranges. The timeline shows how your balances evolve over time and flags any periods where balances would go negative.

The timeline chart shows your projected combined balance alongside how much is safe to spend on each date: the lowest balance from that day forward, so hours needed for vacations you've already planned stay reserved. Pick a date (or click the chart) to see exactly how much you could book that day. In the list below the chart, consecutive accruals are collapsed into one row per stretch between vacations and year-end rollovers, and you can expand a row to see each accrual.
